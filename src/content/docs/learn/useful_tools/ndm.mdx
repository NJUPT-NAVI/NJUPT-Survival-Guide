## 简介

浏览器自带的下载是单线程的：一个文件从头下到尾，速度慢，网络一抖还容易前功尽弃。

NDM（Neat Download Manager）把一个文件切成多段同时下载，速度能翻好几倍；下到一半断了也能接着下。它免费、无广告，常被当作付费软件 IDM 的平替。

## 安装

官网下载：[Neat Download Manager 官网](https://neatdownloadmanager.com/index.php/en/)

点击右上角图标下载，双击一路 Next 即可（也有 macOS 版）。安装包只有一两 MB，没有任何捆绑软件。

## 基础使用

### 接管浏览器下载

NDM 靠浏览器扩展来接管下载任务。

官网首页就有 Chrome / Edge / Firefox 的扩展链接，也可以在浏览器的扩展商店里搜索 "Neat Download Manager" 安装。

装好之后，在网页上点击下载链接会自动弹出 NDM 的下载窗口，不再走浏览器自带的下载。

### 常用功能

- 复制链接后，点主界面左上角的 `+` 手动新建下载任务
- 设置里可以限制下载速度（挂着下载打游戏时有用）
- 同时下载的任务数量可以调
- 断点续传：下载中断后可以继续，不用从头再下

## 使用心得
