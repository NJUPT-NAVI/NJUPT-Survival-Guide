## 简介

大学里打交道的文档几乎都是 PDF：课件、论文、实验报告模板、各种申请表。浏览器只能"看"不能"改"，Adobe Acrobat 功能全但要订阅付费。

PDFgear 把阅读、批注、编辑、转换这些日常功能全部免费提供，导出也没有水印。

## 安装

官网下载：[PDFgear 官网](https://www.pdfgear.com/zh/)

支持 Windows 和 macOS（也有手机版）。下载安装包后双击安装即可，没有捆绑软件，装完即用，不强制注册账号。

## 基础功能

### 阅读与批注

高亮、下划线、手写批注、添加文字备注都有，看课件划重点够用。

### 格式转换

PDF 转 Word / Excel / PPT / 图片，也能反过来转。填电子表格、交作业要换格式时很快。

### 合并与拆分

多个 PDF 合成一个，或者从一个 PDF 里抽出某几页。整理复习资料、拼交材料时用得最多。

### OCR

扫描件、图片型 PDF 里的文字可以直接提取成能复制的文本，速度非常快。
