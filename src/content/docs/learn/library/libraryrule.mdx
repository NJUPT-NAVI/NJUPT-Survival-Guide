# 图书借阅

借书时学生需要使用校园卡在一楼自助借阅机进行借阅，还书时不需要校园卡即可还书。关于书籍借阅的详细规章制度可以参考学生手册，以下内容即摘录自学生手册

## 借书册数

1. 研究生和本科生每人30册。
2. 上述各类读者的借书册数指在三牌楼图书馆、仙林图书馆及集成电路学术图书馆所借图书、光盘的累计总数，其中随书光盘每证限借1盘，密集书库图书每证限借5册。外文原版图书本科生每证限借1册，研究生每证限借2册。
3. 报纸、现刊、精装合订本期刊一律不外借，若需要复印，可办理借出复印手续，但须于当日复印后即刻归还，未及时归还者，酌情处理。
4. 随书光盘凭已借图书到借还总台借该书随书光盘。

## 借阅期限

1. 本科生借阅时间为30天，研究生借阅时间为60天，
2. 随书光盘借阅时间为1天，每超过一天应交违约金1元/盘
3. 当天所换书籍，本人当天无法再借

## 续借

除随书光盘外，所借图书到期前若无人预约，可续借一次，续借期为30天。读者可根据需要，到服务台或自行在网上办理续借手续，续借借期自续借之日算起，过期图书不接受续借。

## 预约

除随书光盘外，其它图书均可办理预约。预约图书的状态必须是“借出”，总计允许预约3册。图书状态为“续借”、“怀疑遗失”、“在库可借”者不能实现预约。预约书到馆通知发出后，被预约图书将保留3天，3天后系统自动取消。

## 逾期处理

1. 读者所借随书光盘应按期归还，逾期不还者，按照每盘每天1元交纳违约金。读者所借图书应按期归还，逾期不还者，外文原版图书按照每册每天0.5元交纳违约金，中文图书按照每册每天0.10元交纳违约金。
2. 在学校规定的寒暑假期间到期的图书，必须在开学后十天内归还，否则从开学后第十一天起计算违约金。假期前到期的图书，假期时间计入超期时间中。学生毕业、退学、休学等均须到图书馆办理图书及欠费清还手续。

## 一卡通借阅功能管理

1. 新生的一卡通号码由图书馆统一设置为读者借书证号，借阅功能在图书馆统一进行的新生入馆教育后开通。
2. 一卡通只限本人使用，不得转借。挂失与补办由学校“校园一卡通中心”负责，挂失手续生效前，一卡通上所有已借出图书的清还责任均由证件所有人自负。
3. 因休学等原因暂时离开学校，应将所借书刊资料全部还清，并暂停一卡通图书馆服务功能后方可离校，回校后再办理恢复开通手续。
4. 因毕业、退学等原因离开学校前，应带上一卡通和离校单到图书馆读者服务部办理离校手续，将所借图书全部还清并结清所有费用，注销一卡通图书馆各项服务功能后，方可办理离校手续。

## 违规与赔偿

《图书馆文献资源保护条例》的要点如下：

1. **窃书行为**：未办理借阅手续将图书擅自带出图书馆、冒用他人一卡通借书、擅自删改数据、蓄意破坏磁条等，均按偷窃书刊处罚，责令书面检查并通报批评，停止借阅权限 60—180 天，并按最低 50 元至该书原价 10—30 倍罚款，情节严重、态度恶劣者送交学校有关部门给予行政处罚。将图书无意带出的，对责任者处以最低 20 元至该书原价 3 倍罚款，并予以馆内通报批评。
2. **污损、毁坏书刊光盘**：在书刊上勾划、批注，将书刊弄坏、弄脏、弄湿等均属污损行为，视情节轻重处该书 1—2 倍罚款；剪、割、撕、挖书刊属毁坏行为，视情节轻重处该书 3—10 倍罚款。光盘盘面有明显划伤按原价 2 倍赔偿，严重划伤或开裂损坏按原价 3 倍赔偿，光盘塑料外壳损坏按 2 元/个赔偿。
3. **遗失赔偿**：遗失书、刊、光盘或严重污损无法使用的，应及时办理挂失及赔偿手续，从挂失之日起两周内办理赔书或赔款。赔书必须是相同书名、作者、出版社原版的新书，同时交纳新书加工费每册 5.00 元；确实无法购到时以现金赔偿：一般中文、外文影印版图书按原价 3 倍赔偿，工具书按原价 4 倍赔偿，珍贵图书、进口原版图书、有较高收藏价值的孤本书按原价 6—10 倍赔偿，89 年以前出版的或具有较高收藏价值的图书可酌情按书价 10—20 倍甚至 30 倍赔偿、最低 50 元；遗失多卷书与整套书其中一本以上的，按整套单价赔偿。

## 智盟卡与新生入馆教育

### 江苏省高校智盟卡

我校统招本科生、硕士生、博士生以及博士后和教职工均可自主申请开通江苏省高校智盟卡，凭此卡身份码即可前往联盟高校图书馆借阅对外开放的图书。

1. 关注“江苏省高校数字图书馆 JALIS”微信公众号，在菜单栏“智盟卡”-“首次绑定认证”中完成联盟统一身份认证（机构选择“南京邮电大学”）。
2. 打开智盟小程序，阅读并接受服务协议、授权手机号登录即可使用，可检索联盟馆藏、查看各联盟高校的进校入馆规则，入馆时出示身份码完成认证。
3. 借还图书凭智盟小程序中的身份码，由各高校馆工作人员在借还平台操作，暂不支持自助借还机。每位用户最多可同时借阅 5 本图书，借期 1 个月，不可续借。

### 新生入馆教育

新生入馆教育采取线上为主、线下辅助的方式进行，介绍馆藏布局、文献类型、图书分类法、文献检索方法、规章制度和服务项目等内容。新生入馆教育作为新生入学手册的内容随录取通知书发放，新生接到录取通知书后就可以开始观看培训视频并答题考核，直到开学报到为止；考核不合格的学生，入校报到后由图书馆集中培训并再次考核。
