### 食堂介绍

<Steps>

1. 南一
   - 定位：最早的三层老食堂，梅兰一条街末端，靠近**教学楼**（附近：**蜜雪冰城、二手书店**）
   - 楼层：
     - 1F 甜品/饮料 + 快餐；
     - 2F（外侧）新疆风味；
     - 3F 台球馆 / 家常菜 / 火锅
   - 高峰：工作日 11:40–12:10，18:00 前后
    :::tip[小贴士]
    - 3F 桌子上有免费插座
    :::

2. 南二
   - 定位：三层，靠近图书馆与晨跑起点
   - 楼层：
     - 1F 中式快餐 / 面包房 / 奶茶店 / 小超市；
     - 2F 风味小吃、面食；
     - 3F “一站式”学生社区（非餐饮，提供事务办理、师生交流、活动空间等服务）
   - 高峰：晨跑后、11:45、18:00
   :::caution[注意]
   南二食堂目前重装升级中，窗口业态可能调整。
   :::

3. 南三
   - 定位：最新翻新（2025 暑期）三层，含 **蜜雪冰城 / 麦当劳 / 小吃街**；外有**大型超市**
   - 楼层：
     - 1F 轻食 / 早餐 / 特色小吃；
     - 2F 正餐 + “人民邮电局”主题聚餐区；
     - 3F 休闲娱乐
   - 高峰：晨跑日 7:20–7:40；午 11:50；晚 18:10 左右

4. 南四
   - 建设中，敬请期待

</Steps>

#### 宿舍相关问题

##### 宿舍是如何确定下来的？
宿舍和床铺由学院统一分配，开学报到时才能知道自己的宿舍和床位。通常一个寝室尽可能分配同一个专业的同学。

##### 宿舍门禁是几点？
宿舍门禁为晚上 23:30。洗澡热水供应时间为 11:00-24:00，24:00 停止供应洗澡热水。

##### 热水、洗衣怎么解决？
- 喝的热水一般在宿舍楼一楼的热水房。
- 仙林校区打热水一般使用智慧校园卡，但樱苑打热水需使用“胖乖生活”APP 或用支付宝扫条形码付费；竹苑、桂苑需使用支付宝“趣智校园”。
- 洗衣：仙林校区除樱苑每层楼设有固定公用洗衣机外，其他宿舍苑区宿舍内留有安放洗衣机的地方，可由宿舍同学一起购买。

##### 宿舍可以换吗？
目前几乎不行，但身高较高的男生可以申请加长床。学校宿舍床铺标准内径长约 1.9 米，学校在男生宿舍集中定制了一批加长床铺。
申请加长床安置住宿的新生须同时符合以下2个条件：
- 一是身高1.88米及以上（以体检信息为准）的仙林校区和三牌楼校区男生; 
- 二是本人知晓不与本班同学共同住宿，而是与其他班级和学院的同性别超高学生混宿并且愿意服从这样安排。

:::note[【年度信息】]
2026级符合条件的同学需于8月16日24点前填写学院统计表，具体安排以当年学院通知为准。
:::
