## 2026级报到安排速览

:::note[【年度信息】]
本小节为 2026 级新生的安排，仅供快速参考，具体时间、地点请以当年学校通知为准。
:::

<Steps>

1. 报到时间与地点
   - 报到时间：**9月5日 8:00-18:00**，请按通知时间报到，**不要提前到校**。
   - 本科新生报到地点：仙林校区**图书馆西广场** / 三牌楼校区**东门学4楼西主干道** / 锁金村校区**篮球场**。
   - 研究生新生报到地点：仙林校区图书馆西广场 / 三牌楼校区东门学4楼西主干道 / 集成电路科学与工程学院（产教融合学院）浦口办学点（浦口区浦滨路88号） / 红枫科技园（栖霞区红枫科技园D5栋科技人才公寓）。
   - 注意：**工商管理、人力资源管理、财务管理（拔尖创班）、财务管理、大数据管理与应用、信息管理与信息系统+人工智能** 等6个专业的新生在三牌楼校区报到，其他专业的新生（除浦口办学点外）在仙林校区报到。

2. 接站安排
   - 9月5日 8:00-17:00，学校在**南京站南广场、南京南站北广场**安排车辆接站，新生凭《录取通知书》乘车，届时请留意接站标志。

3. 校门开放
   - 迎新期间校门**24小时开放**，进校车辆**免收停车费**，新生凭《录取通知书》即可入校。
   - 开放校门：仙林校区东门、北门、南门；三牌楼校区东门；锁金村校区西门。

4. 携带材料
   - 录取通知书、身份证、准考证、学生本人档案（省、自治区、直辖市招办集中寄送学校的除外）。

5. 体检
   - 时间：**9月6日-11日**，各学院的具体时间和地点见“新生体检安排表”。
   - 体检前一天请清淡饮食、避免剧烈运动，体检当日无需空腹；请带好身份证，现场刷身份证打印体检条码，以班级为单位提前15分钟到达体检地点。

6. 军训
   - 时间：**9月8日-22日**。
   - 军训服请于9月5日16:00前试穿；如领取的军训服装尺寸差别较大，可于**9月5日14:00-17:00、9月7日10:00-12:00**到军训服发放点调换（调换衣服前不得清洗）。

</Steps>

## 本科新生报到流程

<Steps>

1. 报到
   - 已缴费新生持《录取通知书》直接到所在学院报到点报到。
   - 未缴费新生请先缴费；绿色通道新生按正常流程报到。

2. 领取材料
   - 领取校园卡、宿舍钥匙等新生材料。

3. 领取军训服
   - 仙林：国防生楼门口
   - 三牌楼：学四洗衣房门口

4. 自愿选购卧具
   - 仙林：各新生宿舍组团门厅
   - 三牌楼：学三楼和学四楼之间的广场、学六楼门厅
   - 锁金村：7栋一楼门厅

</Steps>

## 研究生新生报到流程

<Steps>

1. 报到
   - 已缴费新生持《录取通知书》直接到所在学院报到点报到。
   - 未缴费新生请先缴费；绿色通道新生按正常流程报到。

2. 领取材料
   - 领取校园卡、宿舍钥匙等新生材料。

3. 生活用品与卧具
   - 生活用品按通知书要求自备。
   - 也可自愿选购卧具：
     - 仙林：各新生宿舍组团门厅
     - 三牌楼：学三楼和学四楼之间的广场、学六楼门厅

</Steps>
