:::tip[2026级新生：入学前先搞定易班任务]
【年度信息】以下为 2026 级安排，请以当年通知为准。

入学前请先下载**易班 APP** 并完成**校方认证**（学校选择“南京邮电大学”，认证编号填**本人身份证号码**），认证完成后加入新生入学教育课群（邀请码 **LAR9H6W2**），从易班 APP 首页进入“共筑美好大学梦”轻应用即可参与。四项必做活动：

1. **老师，我想对您说**：跟辅导员打个“文字招呼”，课群 → 在线作业 → 提交信件（截止 9月10日）；
2. **规划生涯，圆梦南邮**：给一年后的自己写封信，课群 → 在线作业 → 提交（截止 9月10日）；
3. **阅读经典，书香校园**：从推荐书单选一本经典阅读并提交读书报告，可获 0.5-2 个自主个性化学分（截止 10月1日）；
4. **《学生手册》知识测试**：易班优课 → 课群（邀请码 LAR9H6W2）→ 在线考试，可反复作答，成绩计入入学教育考核。

若认证失败，多为学校暂未导入信息，可联系南邮易班官方QQ 3288269865 或答疑群 280607818，等待导入后再认证。
:::
